\# Demographic Datasets Directory



\- \*\*Authoritative Source:\*\* Census India Portal (`https://censusindia.gov.in/`).

\- \*\*Baseline Vintage:\*\* Census 2011 historical baseline data.

\- \*\*Proxy/Derived Variables:\*\* Ward-level outdoor worker exposure and senior population density estimates derived via documented spatial proxy models. Current 2026 populations are strictly avoided to prevent data fabrication.
